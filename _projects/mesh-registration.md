### Overview

3D Computer Vision Project: “Optimal step non-rigid ICP mesh registration algorithm” 
Implemented an efficient mesh registration algorithm in PyTorch and Open3D. The algorithm uses deep learning and advanced 3D mesh analysis techniques to align human meshes to the uniform template.
